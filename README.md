# Курс тенге НБРК

Официальный курс тенге Национального банка Республики Казахстан для калькуляторов стоимости на сайте.

Робот GitHub каждые 4 часа берёт курс из ленты https://nationalbank.kz/rss/rates_all.xml и, если курс изменился, сохраняет его в `rate.json`. Файл доступен по адресу:

https://easystandart-hub.github.io/kzt-rate/rate.json

```json
{
  "source": "Национальный банк Республики Казахстан, nationalbank.kz",
  "date": "2026-11-21",
  "usd": 455.0,
  "eur": 498.77
}
```

`usd` и `eur` — сколько тенге стоит 1 доллар и 1 евро на дату `date`.

Если НБРК не ответил или прислал странные данные, робот завершается с ошибкой, GitHub присылает письмо о сбое, а в файле остаётся последний сохранённый курс.
